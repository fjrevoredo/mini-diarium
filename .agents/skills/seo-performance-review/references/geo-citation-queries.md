# GEO Citation Spot-Check Query Set

A **fixed** ~30-query set for the recurring GEO citation baseline. Keep it stable across cycles
so movement is comparable. Run each query on **ChatGPT, Google AI Overviews, Perplexity, and
Copilot**. For each engine/query record:

- **Cited?** Is `mini-diarium.com` (or the app by name) present in the answer or its sources?
- **Absorbed?** Does the answer language reflect the site's framing (offline, no cloud,
  AES-256-GCM, local-first, MIT/open source)?

Report presence + absorption per engine as a directional baseline vs the prior cycle. Do not
over-precise; AI citation is volatile and engine-specific (`STRATEGY.md` §5).

Grouped by the cluster map (`STRATEGY.md` §3). Add a query only if a cluster gains durable
demand; removing a query breaks comparability, so prefer to keep the set stable.
