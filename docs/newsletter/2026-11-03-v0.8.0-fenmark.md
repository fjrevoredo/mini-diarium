Mini Diarium has a new name: Fenmark. Version 0.8.0 is out today, and the website now lives at fenmark.app (old links forward there).

Only the name changes. It is the same encrypted, offline, open-source journal. Another journaling app felt our names were too close, and that was fair, so every name you see changes and nothing under the hood does.

You do not need to do anything:

- Your journals, settings and backups stay where they are.
- On Windows, the installer replaces the old Mini Diarium entry.
- On macOS, delete Mini Diarium.app after you install Fenmark.app. Your journals are not inside it.
- The winget, Homebrew and Flatpak install commands keep working.

As always, reach me through GitHub or the project's email with any questions.
