## Goal

Implement all 23 SEO/GEO improvement items from the May 2026 audit. Unlike the original draft, this plan respects the site's architecture: **generated output files are never edited directly**. Every change targets either the source Markdown, the HTML generator scripts, or the truly static pages.

---

## Architecture Clarification

The website has three layers:

| Layer | Files | Editable directly? |
|---|---|---|
| **Static pages** | `index.html`, `encrypted-journal/index.html`, `privacy/`, `compare/` | Yes |
| **Generated pages** | `blog/*/`, `blog/index.html`, `docs/*/`, `docs/index.html` | No — edit the generators or sources |
| **Generated data files** | `sitemap.xml`, `llms.txt`, `blog/feed.xml` | No — regenerated from sources/generators |

**Rule: Edit `scripts/generate-website-blog.mjs` and `scripts/generate-website-docs.mjs` for blog/docs changes. Edit source `.md` files for content changes. Edit static HTML files only for truly standalone pages.**

The `bun run website:build-static` command runs all three scripts in sequence, so a single run updates everything.
